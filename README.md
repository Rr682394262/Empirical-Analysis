First run ControlManagerD, then DeployerD.
DeployerD code contains three experiments evaluating execution time under different SAG configurations.
SAG Levels vs Execution Time (experiments_levels): studies how the number of hierarchy SAG levels affects execution time with fixed density.
Density vs Execution Time (experiments_density): studies how component density affects execution time with a fixed number of SAG levels.
Combined Analysis (experiments_vectors): evaluates the joint impact of SAG levels and density on execution time.
